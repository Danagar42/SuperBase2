# Специфікація дизайну: Шпаргалка лінеаризації в стилі SuperBase

Цей документ описує дизайн та архітектуру переносу застосунку «Шпаргалка лінеаризації напружень» в окрему папку та оновлення її інтерфейсу відповідно до дизайн-системи SuperBase.

## 1. Загальні вимоги та мета
*   **Мета**: Інтегрувати застосунок «Шпаргалка» в екосистему SuperBase, забезпечивши 100% візуальну єдність та відповідність кольоровій гамі, шрифтам та компонентам SuperBase.
*   **Локація**: Всі файли шпаргалки переносяться в окрему папку `шпаргалка/` у корені проекту:
    *   `шпаргалка/index.html` — основний файл застосунку.
    *   `шпаргалка/styles.css` — винесені стилі шпаргалки.
*   **Оригінальний файл**: `Шпаргалка.html` у корені проекту видаляється після завершення інтеграції.
*   **Колірна палітра**: Повна заміна бренду ANSYS (жовтий/чорний) на преміальний індиго/темно-синій/сірий стиль SuperBase.

## 2. Структура інтерфейсу та UI-компоненти
Для реалізації преміум-дизайну застосуємо Tailwind CSS та кастомний `styles.css`.

### 2.1. Шапка (Header)
*   **Висота**: `h-[72px]`.
*   **Стиль**: Скляний ефект (glass-panel, blur, `backdrop-filter`), тонкий бордер знизу (`border-b border-slate-200 dark:border-slate-800`).
*   **Логотип**: Преміум SVG-логотип SuperBase (аналогічно `index.html`).
*   **Заголовок**: «SuperBase» з бейджем «Шпаргалка лінеаризації» кольору індиго.
*   **Перемикач теми**: Кругла кнопка з SVG-іконками Сонця/Місяця.

### 2.2. Головний контейнер та сітка
*   **Розмітка**: Гнучка флекс-коробка (`flex flex-col h-screen overflow-hidden`), яка ідеально вміщує таблицю без виходу за межі екрана.
*   **Контейнер таблиці**: Fluent-карта (`fluent-card`) із заокругленням кутів, тонкою рамкою та ефектом розмиття заднього фону.
*   **Тіні та свічення**: Клас `brand-glow` для карт для надання преміального свічення в темній темі.

### 2.3. Таблиця (Spreadsheet)
*   **Шрифти**: Сімейство шрифтів **Inter** для всієї сторінки, моноширинний **Consolas** або **Courier New** для значень напружень та імен шляхів.
*   **Виділення осередків (Excel Selection)**:
    *   Клас `.cell-selected` забарвлює виділені осередки $S_1$, $S_2$, $S_{rv}$ в ніжний колір індиго (`#e0e7ff` у світлій темі, `rgba(99, 102, 241, 0.2)` у темній) з рамкою кольору індиго.
*   **Іконки дій**:
    *   Заміна emojis (`📋`, `✖`, `⧉`, `↶`, `↷`, `☰`) на професійні SVG-іконки:
        *   Копіювати стовпець: іконка буфера обміну.
        *   Дублювати рядок: іконка копіювання шарів.
        *   Видалити рядок: іконка сміттєвого кошика або хрестика.
        *   Drag Handle: іконка шести точок (grip-vertical).
        *   Undo/Redo: вигнуті стрілочки назад/вперед.

### 2.4. Зони та динамічні кольори
*   Збережемо колірне маркування категорій зон, але адаптуємо кольори до більш холодних, пастельних тонів, що пасують до темно-синьої та сірої гами:
    *   Фланець (Flange): Ніжно-синій.
    *   Зона приварки: Бірюзовий/Смарагдовий.
    *   Болти/Шпильки: М'який бурштиновий.
    *   Обичайка: Фіолетовий.
    *   Плоска кришка: Рожевий.
    *   Еліптичне днище: Ціан.
    *   Зона патрубка: М'який червоний.
    *   Трубна дошка: Тіловий.
*   Ці кольори будуть виражатися у вигляді тонкої лівої смужки інпуту (`border-l-4`) та легкого напівпрозорого фону в темній та світлій темах.

### 2.5. Модальні вікна та сповіщення (Toasts)
*   **Toasts**: Інтеграція динамічного `toastContainer` з плавним виїздом знизу та зникненням вправо.
*   **Confirm Modal**: Діалогове вікно з блюром фону, заокругленими кнопками та преміум-дизайном.

## 3. Автоматична синхронізація тем
*   Темна тема застосовується через клас `dark` на тегу `<html>`.
*   Тема зберігається в `localStorage.theme` (як і в основному SuperBase), що забезпечує автоматичну миттєву синхронізацію: перемикання теми на будь-якій сторінці синхронізує її для всього проекту.

## 4. Збереження функціональності
Буде збережено 100% оригінальної логіки:
*   Розрахунок лінеаризації за зонами ($S_1$, $S_2$, $S_{rv}$).
*   HTML5 Drag and Drop перетягування рядків таблиці.
*   Excel-style копіювання виділених осередків (із збереженням структури з розділювачами табуляції `\t`).
*   Гарячі клавіші (Enter для додавання рядка, Delete для видалення, Esc для зняття виділення, Ctrl+A для виділення всіх рядків, Ctrl+Z / Ctrl+Y для скасування/повторення).
*   Локальне збереження стану таблиці (`localStorage.ansys_paths_state`).
